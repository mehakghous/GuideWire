*****
Bevel
*****

.. reference::

   :Mode:      Edit Mode
   :Menu:      :menuselection:`Vertex --> Bevel Vertices`, :menuselection:`Edge --> Bevel Edges`
   :Shortcut:  :kbd:`Shift-Ctrl-B` (Bevel Vertices), :kbd:`Ctrl-B` (Bevel Edges)

The bevel tool rounds off sharp corners. This synthetic page was written for the test-suite
and only imitates the layout of the real manual.

.. seealso::

   The :doc:`/modeling/modifiers/generate/bevel` does the same without changing the mesh.

Usage
=====

Pick some edges, press the shortcut, then drag the pointer to set the width.
