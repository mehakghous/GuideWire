*********
Subdivide
*********

Subdivide splits edges and faces into smaller parts. Synthetic page for the passage-ranking test.

Cuts
====

The number of cuts sets how many new edge loops are added between each original pair of edges.

Smoothness
==========

The smoothness value pushes the new vertices toward a rounded surface instead of keeping them on the flat original.

Fractal
=======

The fractal option displaces new vertices at random to give a rough, rocky look.

Pattern
=======

The grid fill pattern decides how quads are joined when a face is cut across several edges.
