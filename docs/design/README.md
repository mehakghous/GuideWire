# UI design options

Design mockups only. Nothing here is applied to the app.

- `option-0-bauhaus/`: Bauhaus direction, one red accent on black and paper white.
- `option-1-plum-olive/`: Alabaster Gleam, Plum Wine and Olive Drab, Title Case, new logo. No characters.

Each folder is a Design canvas project: `canvas.json` is the index and each `*.dc.html` is one screen or component.
