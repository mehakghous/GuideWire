***************
Normals Display
***************

Normals describe which way a face points. Synthetic page for the passage-ranking test.

Flip
====

Flip reverses the direction of the selected faces so that the inside becomes the outside.

Recalculate
===========

Recalculate outside orients all selected faces consistently so that they point away from the volume.

Custom
======

Custom split normals store a hand edited direction per corner of the face, which survives edits to the geometry.

Threshold
=========

The angle threshold decides which edges look sharp when shading is smoothed automatically.
