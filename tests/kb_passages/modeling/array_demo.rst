**********
Array Demo
**********

The array modifier repeats an object many times. Synthetic page for the passage-ranking test.

Count
=====

The count setting chooses how many copies are made, including the original.

Offset
======

Relative offset spaces each copy by a multiple of the object size, while constant offset uses a fixed distance.

Merge
=====

The merge distance welds vertices of neighboring copies that are closer together than the value.

Caps
====

Start and end caps place a different object at the first and last copy of the chain.
