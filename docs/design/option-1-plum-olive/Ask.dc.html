Why do we parent the mesh with automatic weights?
The tutorial does not say why, so I will not guess from it. In general, automatic weights tell Blender how strongly each bone pulls each part of the mesh, so the mesh bends when you move a bone. You can paint the weights later if a joint looks wrong. General knowledge, not from the video. Model answer, about 0.1 cent.
